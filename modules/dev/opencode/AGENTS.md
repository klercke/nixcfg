# Personal conventions

- You are on a NixOS system.
  Do not attempt to install anything using a package manager or curl-bash installers.
  Missing tools will be installed in a repo's flake or in my system's config.
- I prefer solving per-project problems with devShells and direnv instead of wrapper scripts.
- I have many shell aliases that in some cases change default behavior of commands.
- My NixOS configuration can be referenced here: https://gitlab.com/klercke/nixcfg.
- I use GitHub and GitLab so a repo's remote will need to be checked before assuming one over the other.
- When writing Markdown, I use the LaTeX-style standard of one sentence per line.
- I do not generally like to use symbols that are not available on standard keyboards when writing comments, documentation, or other prose.
- I use Conventional Commits and SemVer wherever possible.
- Do not blindly disagree with me.
  Engage me on why I am right or wrong and let's have a discussion.
- Do not EVER make a git commit, a push, or modify a remote without asking first.
